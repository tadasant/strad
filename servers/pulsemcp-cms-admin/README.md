# pulsemcp-cms-admin — strad bundle tree

PulseMCP's CMS admin MCP server: the MCP server directory, the newsletter, the
official and unofficial mirror queues, tenants and their API keys, redirects,
background jobs, Proctor exam results, discovered URLs and MOZ metrics, all
through the admin API at `https://admin.pulsemcp.com`.

**Regime: VENDOR.** `shared/` is copied unchanged from
[`pulsemcp/mcp-servers` `experimental/pulsemcp-cms-admin/shared`](https://github.com/pulsemcp/mcp-servers/tree/main/experimental/pulsemcp-cms-admin),
vendored at `cca9d52`. The one difference is `shared/package.json`, which
resolves `@pulsemcp/mcp-elicitation` as a workspace (`"*"`) instead of
upstream's `file:../../../libs/elicitation` path — the same edit `onepassword`
carries. **Do not edit `shared/src` here.** A fix to it lands in strad, by
promoting this tree to PATCHED VENDOR or FORK first (a delta table here and a
`HACKS.md` entry, or a `FORK.md`), never as a silent edit a re-vendor would
undo.

## Layout

```
servers/pulsemcp-cms-admin/
  elicitation/  # @pulsemcp/mcp-elicitation, unpublished on npm; shared/ imports it.
                # src/ is GENERATED by `npm run elicitation:sync` from
                # servers/onepassword/elicitation/src. Edit it there.
  shared/       # VENDORED VERBATIM: the 74 tools and the admin API client
  test/         # strad's suite, outside the vendored tree
```

There is no `remote/`. The bundle host (`servers/bundle/host/src/index.ts`,
`loadPulseAdmin`) imports `createMCPServer` from the built `shared/` and passes
it a client factory.

## Environment

| Variable                         | Required | What it is                                                                                           |
| -------------------------------- | -------- | ---------------------------------------------------------------------------------------------------- |
| `PULSEMCP_ADMIN_API_KEY`         | yes      | An admin API key, sent as `X-API-Key`. Read-only or read-write; the key decides what the API allows. |
| `PULSEMCP_ADMIN_API_URL`         | no       | The admin API origin. Defaults to `https://admin.pulsemcp.com`.                                      |
| `PULSEMCP_ADMIN_INTERNAL_SECRET` | no       | Sent as `X-PulseMCP-Internal` so Cloudflare's rate limits skip the request. Read from the bare name. |

The image is credential-free. With no key the mount still lists its tools,
reports itself degraded, and every call fails naming the variable.

**One instance per key.** A slug at `path: /<its own slug>` whose `env:` sets
`PULSEMCP_ADMIN_API_KEY` gets a mount of its own, built from its own key and its
own `PULSEMCP_ADMIN_API_URL` — never a sibling's. That is how a deployment
serves a read-only and a read-write key as two slugs. See
`docs/src/content/docs/servers/pulsemcp-admin.md`.

## What strad does not serve

`TOOL_GROUPS` is scrubbed on the bundle (capability is the gateway's `tools:`
policy), so every mount serves the upstream default: **71** tools, every group
except `tenants_destructive`. `delete_tenant`, `delete_api_key` and
`revoke_api_key` are not reachable through strad; upstream gates them behind an
elicitation prompt, and strad has not wired one for this tree. `HACKS.md` #153.

Run `npm test` here for the suite: the surface, the read-only subset, the key
and origin on the wire, and a missing key failing the call rather than the
process.
